# 使用说明与提交清单

项目名称：InvoiceFlow 企业发票支付与对账平台。

## 怎么运行

先按 README 安装 Node.js 和 Python 依赖。三个终端分别启动本地区块链、部署合约、启动 Flask。浏览器打开 http://127.0.0.1:5000。

选择 Use local test wallets。Merchant wallet 是商户，Customer wallet 是客户。创建发票时客户地址使用：

`0x70997970C51812dc3A010C7d01b50e0d17dc79C8`

先用商户创建发票，再切换客户付款，然后对账，最后切回商户提款。付款是真正在本地 EVM 上执行，不是网页假数据。本地钱包适配器不是 MetaMask；正式钱包入口是 Connect MetaMask。

## 你需要理解的重点

1. Flask 提供网页、认证、资料存储和对账，不保管用户私钥。
2. MetaMask 负责用户签名；合约强制执行金额、付款人和状态规则。
3. 钱包拿到交易哈希不等于成功，必须检查收据与确认数。
4. 对账结果来自链上事件和合约状态，不能通过网页提交“已付款”伪造。
5. 发票文字放在 SQLite，链上存内容哈希，修改资料后完整性验证失败。
6. 商户提款遵循先检查、再更新余额、最后付款，并加重入锁。

## 提交前

- 阅读报告，补全姓名和学号。
- 了解所有代码，按课程要求披露 AI 辅助。
- 若老师要求 Sepolia 或云端链接，执行 README 的部署流程；提供真实交易哈希，不能把本地测试说成 Sepolia 测试。
- 使用真实 MetaMask 插件验证钱包连接、拒绝签名、账户切换和网络切换。
- 看一遍视频；视频会明确标注本地链测试。可按演示脚本用自己的声音重新录制。
- 提交报告 PDF、代码、截图、README 和 5–8 分钟视频。
